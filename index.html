  1. 用 Chrome 或 Edge 桌面版打开本页（手机浏览器不支持）。
  2. 用 USB 线连接阅读器与电脑。
  3. 点下方按钮，在弹窗中选择串口并确认。
  4. 等待进度条走完，设备自动重启即完成。
当前浏览器不支持 Web Serial，请改用桌面版 Chrome / Edge。 本页必须通过 HTTPS 打开才能刷机。

注意事项
  • 首次从原厂固件刷入会重写分区表，建议在弹窗中勾选"擦除设备"。
  • 擦除只影响设备内部存储；SD 卡中的书和进度不受影响。
  • 刷机过程中不要拔线或关闭页面。
  • 若无法识别串口，换一根能传数据的 USB 线，或换一个 USB 口再试。
